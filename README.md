Enterprise Student Record and Academic Management Platform

Project Description

This project develops a student academic management platform using DevOps practices.

Modules

- Student Management
- Faculty Management
- Course Management
- Enrollment Management
- Grades and GPA Calculation

Technologies

- Python and Flask
- Pytest
- Git and GitHub
- Jenkins
- Docker
- Kubernetes and Minikube

DevOps Workflow

GitHub → Jenkins → Automated Testing → Docker → Kubernetes

Project Objective

To develop an academic management application and use DevOps tools to test, build, and deploy it.
